# 两套主题共用一套布局，主题按账号保存

界面提供「简洁」和「醒目」两套主题。两者共用同一套 DOM 和布局：主题只体现在 `<html data-theme>` 上的 CSS 变量，以及 `components/ui` 里少数基础组件（面板、列表行、徽标、按钮、判断展示等）内部的 `price-tag:` 样式；页面代码不判断当前主题。这样无障碍名称和 e2e 契约只有一份，新页面用基础组件即可同时适配两套主题，e2e 换主题跑同一套用例即可覆盖。

主题保存在 user 表的 `theme` 列，随 `GET /me` 返回、`PATCH /me` 修改，换设备登录仍是同一主题。浏览器另存一份到 localStorage，供 index.html 在首帧前套用，避免刷新时先闪默认主题；以服务端为准。

## Considered Options

- 每套主题各写一套页面组件（被否：两份 DOM，无障碍名称和测试契约会分叉，改一处要改两处）
- 主题只存在浏览器本地（被否：家人在手机和电脑上各设一次，换设备会丢）
